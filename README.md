# Rehabilitation Robot Gait Workbench

康复机器人相关比赛项目的公开工程版本。项目以双目视觉为基础，将相机采集、实时三维人体姿态、步态参数分析、安全门控、轨迹监控和康复报告导出整合到一个 Python 工作站中。

## 项目背景

该工程面向针对性下肢康复和外骨骼辅助训练场景：通过双目相机捕捉人体运动，估计三维姿态和下肢关节运动，实时计算步频、步长、支撑/摆动相、双支撑时间、关节活动范围、躯干摆动、步态对称性和稳定性等指标，并将结果用于康复过程监控和报告生成。

## 主要模块

- `camera_1.py`、`camera_threads.py`：双目相机采集、设备流配置、录像和时间戳处理。
- `realtime_pose.py`：Orbbec 相机帧缓冲、AlphaPose 2D 姿态推理、三维重建和实时姿态更新。
- `gait_analytics.py`：基于 3D 关键点的足部接触检测、步态相位识别、步态时空参数和关节运动分析。
- `gait_metric_safety.py`：对实时指标进行范围检查、时序一致性检查和异常值回退，避免单帧错误污染康复报告。
- `trajectory_monitor_panel.py`：通过 UDP 接收期望/实际轨迹与力矩，进行相位超前、平滑和可视化监控。
- `rehab_reporter.py`：生成中文/英文 HTML 康复报告，汇总步态、关节、稳定性、对称性和疲劳相关指标。
- `clean_step_cycle.py`、`predict_gait_cycle.py`：步态周期相位对齐、归一化和神经网络轨迹预测工具。

## 工程特点

```text
双目采集 → 2D 姿态估计 → 3D 姿态重建 → 步态分析
       → 指标安全门控 → 实时监控 → 康复报告
```

安全门控模块同时检查指标范围、左右侧一致性、步态相位状态和步频/步时关系，能够对异常值进行替换、隐藏或保留最近稳定值，并记录质量标记。

## 运行边界

公开仓库不包含真实受试者视频、标定文件、模型权重、AlphaPose 源码、Orbbec SDK、UDP 实验数据和比赛材料。真实设备运行需要另外安装厂商 SDK、AlphaPose 及对应权重，并按设备型号配置采集参数。

```powershell
python -m pip install -r requirements.txt
python gait_safety_demo.py
```
